A fresh conversation. Try a pause, interrupt a story, or talk while a lookup runs.

Ready

Uses hosted OpenAI speech. Microphone audio goes to OpenAI; test transcripts are saved locally. Each call ends after five minutes. Headphones help isolate conversation timing from speaker echo.
Things to try
  1. “I was thinking …” Pause mid-thought, then continue.
  2. “Tell me a long story.” Interrupt with “Wait, make it about a mango.”
  3. “Start a slow lookup.” While it runs, ask “What is twelve times thirteen?” Then wait for the result.
  4. “Start a failing lookup.” It should explain the failure.
  5. “Start a slow lookup.” Then “Cancel that lookup.” It should stay cancelled.
